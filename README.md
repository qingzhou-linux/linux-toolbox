# Linux工具箱

一个基于 Bash Shell 开发的 Linux 自动化管理工具。

## 功能

- 文件自动备份
- 文件压缩
- 历史备份清理
- 状态查看
- 日志记录
- 配置文件管理


## 安装

执行：

sudo ./install.sh


## 使用

备份：

tool backup 文件名


查看状态：

tool status


清理：

tool clean


查看版本：

tool version


## 技术

- Bash Shell
- Linux文件系统
- crontab定时任务
- tar压缩
- 日志管理
- Linux权限管理
